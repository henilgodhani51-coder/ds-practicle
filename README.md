# Data Structures Implementation & Learning Platform

A comprehensive, interactive web platform covering all **8 Modules** of the university Data Structures curriculum with detailed theory, time/space complexity analysis, complete C code implementations, self-assessment quizzes, and real-time interactive algorithm visualizers.

---

## 📚 Curriculum Coverage (Modules 1 - 8)

| Module | Title | Topics Covered | Interactive Visualizer |
|---|---|---|---|
| **Module 1** | **Introduction to Data Structures** | Basic terminology (Data, Field, Record, File), Primitive vs Non-primitive, Linear vs Non-linear, 6 primary operations, Big-O / Omega / Theta notations. | Concept Cards & Complexity Gauges |
| **Module 2** | **Array** | Contiguous memory allocation, Array ADT in C, Sparse Matrices (dense vs sparse waste), 3-tuple / Triplet representation, Row-Major vs Column-Major address calculation formulas. | 🎯 Array Operations, 3-Tuple Matrix Converter, 2D Memory Address Calculator |
| **Module 3** | **Searching & Sorting** | Linear Search, Binary Search (iterative & recursive), Bubble Sort (with swapped optimization), Insertion Sort, Selection Sort, and Radix Sort (LSD). | 📊 Animated Step-by-Step Searcher & Sorter with Bar Animations |
| **Module 4** | **Stack & Queue** | Stack ADT (LIFO), Array implementation, Infix to Postfix conversion, Postfix evaluation, Recursion call frames, Tower of Hanoi ($2^N - 1$), Queue ADT (FIFO), Circular Queue with modulo arithmetic, Deque, Priority Queue. | 🥞 Stack Cylinder, Postfix Conversion Trace Table, Tower of Hanoi Auto-Solver, Circular Queue |
| **Module 5** | **Linked List - Part I** | Dynamic memory allocation (`malloc`, `calloc`, `free`), self-referential structures in C, Singly Linked List (insert/delete at head, tail, position), Doubly Linked List, Circular Linked List. | 🔗 Node Link Animator with Pointer Links & Head/Tail Operations |
| **Module 6** | **Linked List - II & Applications** | Linked Implementation of Stack, Linked Implementation of Queue, Polynomial representation and Polynomial Addition in C, Free-list memory management. | ⚙️ Dynamic Chain Flow & Polynomial Expression Reducer |
| **Module 7** | **Trees & Graphs** | Tree terminology, Binary Tree, Traversals (Inorder, Preorder, Postorder), General to Binary Tree, Threaded Binary Trees, Binary Heaps (Min/Max), BST, Huffman Coding, AVL Trees (LL/RR/LR/RL rotations), 2-3 Trees. Graphs: Adjacency Matrix & List, BFS, DFS, MST (Kruskal's & Prim's), Dijkstra's Algorithm. | 🌳 Interactive SVG Binary Search Tree Builder, BFS/DFS Graph Explorer |
| **Module 8** | **Hashing** | Symbol Table ADT, Hash Tables, Hash Functions (Division/Modulo, Mid-Square, Folding, Multiplication), Collisions, Open Addressing (Linear Probing, Primary Clustering), Separate Chaining. | ⚡ Live Hash Table & Linear Probing Collision Resolver |

## 🛠️ Key Platform Features

- **⚡ 13+ Interactive Visualizers:** Step-by-step animations for sorting, searching, stack push/pop, queue operations, linked lists, binary trees, graph traversals, and hash tables.
- **💻 Copy & Download Ready C Code:** Every single topic features clean, modular, tested C programs adhering to C99/C11 standards with detailed comments and sample drivers.
- **⏱️ Complexity Analysis Dashboards:** Quick reference cards displaying Best Case, Average Case, Worst Case Time, and Auxiliary Space requirements.
- **📝 Self-Assessment Quizzes:** Interactive multiple-choice tests on every topic with instant answer feedback and thorough explanations.
- **🔍 Instant Search Engine:** Type in search queries (e.g. `AVL`, `Radix`, `Linear Probing`, `Dijkstra`) to immediately jump to matching topics.
- **🌓 Dark & Light Modes:** Seamless toggle with saved user preference.
